# Tripva.in — Test Summary Report

## 1. Project Overview
- **Application:** Tripva.in
- **Application Type:** Bus Ticket Booking Application
- **Testing Type:** Manual Testing
- **Platforms:** Web and Mobile
- **Project Objective:** To validate application functionality, identify defects, and assess the application's behavior against expected results.

## 2. Testing Activities
- Reviewed application features and user workflows.
- Prepared test scenarios and test cases.
- Executed functional checks on relevant application modules.
- Identified and documented defects.
- Recorded expected and actual results for observed issues.

## 3. Areas Tested
- Full Name field validation
- Date of Birth validation
- Email verification
- Profile image upload
- Gender dropdown display
- Radio button functionality
- Email address validation
- Validation message display
- Notification functionality

## 4. Defect Summary
A total of 9 defects were documented based on the testing observations.

- Input validation issues
- Email verification and validation issues
- Profile image upload issue during a network interruption
- User interface layout issue
- Radio button functionality issue
- Notification functionality issue

## 5. Test Outcome
The documented test cases include failures observed during testing. The affected functionalities require further investigation and retesting after fixes are implemented.

## 6. Conclusion
Manual testing helped identify functional, validation, and user interface issues in the application. The documented test scenarios, test cases, and defect reports provide a basis for further investigation and regression testing.
